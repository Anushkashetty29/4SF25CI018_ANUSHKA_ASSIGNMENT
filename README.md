# Pandas Assignment – DataFrame Operations

## About
This repository contains 13 Python programs based on Pandas and NumPy. The assignment focuses on creating and manipulating DataFrames and Series, performing data aggregation, handling missing values, and working with text data.

## Objectives
- Understand Pandas DataFrames and Series.
- Perform basic DataFrame operations.
- Handle missing values using mean imputation and dropna().
- Perform grouping and data aggregation.
- Merge multiple DataFrames.
- Work with MultiIndex DataFrames.
- Apply functions and lambda expressions.
- Perform string operations using Pandas.

## Topics Covered
1. Creating DataFrames and calculating the product of columns.
2. Row-wise and column-wise sum.
3. Handling NaN values using column mean.
4. Dropping rows containing NaN values.
5. Data aggregation using GroupBy, Sum and Mean.
6. Grouping products by category and calculating total sales.
7. Merging DataFrames.
8. MultiIndex DataFrame with indexing and slicing.
9. MultiIndex grouping and sum operations.
10. Applying functions to DataFrames.
11. Using lambda functions to create a new column.
12. Converting text strings to uppercase.
13. Extracting the first three characters of strings.

## Tools and Technologies Used
- **Programming Language:** Python
- **Libraries:** Pandas, NumPy
- **Platform:** Jupyter Notebook

## Conclusion
Through this assignment, I gained practical knowledge of Pandas and NumPy and learned how to perform different data manipulation, aggregation, and text-processing operations using Python.
